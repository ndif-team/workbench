# Login illustrations

- `neural-layers-clean-lines.webp`: selected matrix illustration, with the orange path aligned to the layer perspective.
- `woven-signal-staggered-transparent.webp`: alternate woven illustration with short, staggered thread ends, retained for future use.

Both are 1536 × 1024 lossless WebP assets with transparency, created with OpenAI image generation. Keep their alpha channels when exporting. The signal-focus rings and warm highlight are rendered separately by `LoginFrame` and its CSS, so the artwork remains reusable.

For the thread alternative, the approved desktop preview scales the image to 145% within the existing artwork area to compensate for its transparent margins. Keep any overlay aligned with the same scale.
